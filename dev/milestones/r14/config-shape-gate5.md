**Row 7 is worth its own paragraph, because it looks like a numerical change
and is not.** `REDUCER_HASH` is `kernel_hash(REDUCER_KERNEL, env_fingerprint=
file_digest(pixi.lock))`. None of the six enumerated kernel functions is
touched by this branch (`git diff main..HEAD -- blueearth_cst/projections/`
reaches `change_factor_table.py`, `dry_month.py`, `variable_spec.py` and no
others). The env fingerprint moved instead — and `pixi.lock` is **unchanged in
git** on this branch. The two worktrees hold the same lock file with different
LINE ENDINGS: this worktree's copy is CRLF (664,259 bytes,
`ca888ef1…`), the primary's is LF (646,447 bytes, `d2b1e08e…`, byte-equal to
the committed blob), and `tr -d '\r'` makes them identical. So a checkout
line-ending difference re-keys every CMIP6 series. Boarded as `t2608301524`;
it is a pre-existing defect, unrelated to config shape, and it does not touch a
value anywhere.
