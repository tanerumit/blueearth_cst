Decisions behind the wording

  • Separate the periods. Requested extraction span, actual delivered span, diagnostic reference period, and configured comparison period have different purposes. A time-axis span does not prove daily completeness; common valid reporting years are calculated separately.
  • Separate selected forcing from comparison candidates. The selected source enforces the weather-generator record-length requirement. Extra precipitation-only candidates retain native precipitation without borrowing temperature. ERA5 companion fields are added when a precipitation-only source is selected for forcing, but are not attributed to that source as native temperature.
  • Use live configuration names. Replace stale shared.historical_window with climate.window and stale selection references with climate.selected. A source with an intrinsically short record needs more data, not merely a renamed window.
  • Distinguish written files from usable estimates. WF0 can save placeholder figures and unscaled maps. Report those outcomes separately from figure forms deliberately omitted for unsupported variables. Avoid importing WF2’s “skipped figure” terminology indiscriminately.
  • Explain comparison without implying validation. Source agreement is not accuracy. The overview table reports structural forcing conformance, not scientific suitability. Historical map references set display classes and do not establish an observational truth.
  • Keep operations visible. Retain RUN/DONE, source identities, elapsed durations, warning severity, output paths, and full coverage. Add context where interleaved source jobs are ambiguous.
