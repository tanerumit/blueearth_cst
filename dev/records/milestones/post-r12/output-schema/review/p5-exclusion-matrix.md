## Refused/unsupported branches and contract checks

- `write_netcdf.compression=0` reached the upstream writer and failed in `ncdf4::ncvar_def`, whose supplied compression range is 1–9. `compression=null` failed weathergenr's own numeric validation. Neither was counted as a pass. The owner explicitly approved refusing uncompressed output and comparing supported levels 4 and 9. P5 production validation now refuses null/0 before collection creation, and focused tests cover that admission rule. No upstream package was edited.
- `run_weather_generator.eval_max_grids=1` with `save_plots=true` reduced evaluation to one grid, then failed upstream cross-grid diagnostic plotting (`ggplot2::combine_vars` received no facet values). It was not counted as scientific equality. P5 production now refuses this combination before collection creation, with focused tests; the valid below-two-grid cap was executed with plots disabled and passed. Caps below 1 are refused.
- `workflow enabled=false` is an admission case, not a numerical comparison. P5's `test_disabled_wf3_cannot_initialize_collection` verifies no collection namespace/ready marker. `run_group_id_capacity=15→999` preserves the seed-material digest, changes collection ID `0fcd…`→`5c510…`, and changes IDs 01..14→001..014 while leaving ordered semantic row payloads equal; scratch probe `p5_matrix_contract_probe.py`.
- P5 focused tests establish the full-digest automatic-seed formula and identical collection identity for auto versus explicit requests resolving to the same integer. They also cover template/catalog comments and locators, nested unit-interpretation evidence and WF4-only code exclusion from the generator closure. The direct R provider receives only the resolved integer seed; request spelling does not cross its CLI. Fixed source-byte and YAML-comment execution arms above supply numerical evidence for locator/text invariance. The 32-pass focused suite is `.tmp/scratchpad/2026-09-21_1541/p5-final-focused.log`.
- CHIRPS source-preparation elevation can change the historical source bytes and is therefore a sensitivity/refusal case; this ERA5-only matrix makes no CHIRPS scientific invariance claim. WF4 elevation and settings were not physically supplied to direct R arms; their non-dependency is established by the P4/P5 closure/projection tests, and the fresh WF3-only fixture succeeds without WF4 preparation.
