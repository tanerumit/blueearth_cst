# Developer templates

Reusable starting points for reports and review interfaces. Copy a template into the owning checkout's
task scratch before populating it; the tracked template contains no session-specific results.
See [scratch placement](../reference/repo-layout.md#task-temporary-material) for the destination.

| Template | Usage |
|---|---|
| [workflow-report.html](workflow-report.html) | [Manual workflow report guide](workflow-report.md) |
| [figure-comparison.html](figure-comparison.html) | [Figure comparison guide](figure-comparison.md) |

Keep interface structure and field instructions here. Scientific figure conventions belong in
[plot style](../reference/plot-style.md); retained reports belong with their evidence, not in this folder.
